## Provisional accept/reject contract to freeze BEFORE generation

The scientific endpoint is bounded finite-case subspace utility; it is NOT full-function reconstruction. The candidate rules always return certificatefalse. Predeclare both rules' outcomes and evaluate each independently on every case; never promote whichever wins. Known/half/double width controls are evaluator-only, with requested/effective/clipped collisions preserved.

Proposed rule-level pass requires ALL cases to meet their applicable conditions, including hard cases, with no post-label exclusions. Apply the predeclared side-cutoff sensitivity rule to EVERY nonzero analytic reference, including primary rank=p: a full-at1e-10 reference with a different1e-9 rank FAILS even when the candidate is null. Zero reference fails separately. Sensitivity failures never reduce the denominator:

- Where analytic numerical reference has0<r<p: chosen rank equals r, unweighted lost/extra reference-subspace RMS<=.01, maximum truegate residual<=.01, and minimum of the64 independent random direction residuals exceeds that maximum. Exact/near-degenerate cases use measured reference rank, never force2m equality. Reference sensitivity is predeclared: compute numerical ranks at1e-11 and1e-9 in addition to unchanged primary1e-10. If the side ranks differ, mark reference_rank_sensitive=true and FAIL the rule-level endpoint for that case, preserving all three ranks and spectra; never exclude it or silently choose another cutoff. This factor10 band is a conditioning diagnostic, not a certified reference-error bound. No subjective post-data uncertainty label may change qualification.
- Where analytic numerical reference is fullp: return null. A proper subspace with a large gap must not be called informative on truth-full cases. Full reference membership is uninformative; passing this finite test is not a general fullspace detector theorem.
- Zero reference, nonfinite, underflow/overflow, source/resource/inventory/transport failure: explicit failure/abstention diagnostics, never success or exclusion. A resource/controller failure dominates metrics. Any unexpected valid zero-reference case counts as endpoint failure rather than changing the denominator.
