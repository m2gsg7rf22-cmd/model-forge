# Independent joint-response numerical audit components

These components implement Task1 of the design-approved plan. They do not execute an audit, read actual observations or authorize numerical evaluation. Independent component review must be recorded separately; full-protocol/source/execution approval is still required.

`joint_response_audit_math.py` imports no fitted prediction, loss, selection, optimizer, RNG or data loader. It uses a signed log-magnitude SiLU formula, with local allowance for a negligible saturated logaddexp correction; the final exponential, products and loss/relative metrics retain numerical failure checks. Literal positive input1000 originally triggered an artificial underflow failure; the independent reviewer found it, the regression test failed before the fix and passes after it. Negative input-1000 remains an explicit unrepresentable nonzero SiLU failure, rather than a claimed exact zero. These are floating-point candidate calculations, not interval arithmetic or a proof of every BLAS rounding event.

Streaming square statistics rescale by the observed maximum and sum scaled block squares. Tiny individually unrepresentable terms may round away, but each nonzero block retains a unit maximum; a nonzero residual cannot silently become an all-zero reduction. Block rows<=4096, total components<=71808*32, input/output dimensions<=32, hidden width<=96. RMS can remain finite when unscaled squaring would overflow. Nonzero MSE/half-MSE/relative results that overflow or round to zero fail explicitly. A genuinely zero reference has null relative error, including a nonzero residual; an exact zero residual against nonzero reference has relative0. No thresholds are changed in response to actual observations.

Scalar agreement is abs(delta)<=1e-12+1e-10*abs(reference). Array agreement requires both the maximum-component inequality and the Frobenius inequality in the design; the latter is evaluated as the exactly equivalent RMS inequality after division by sqrt(component count). Selection returns the earliest literal minimum and separately flags any competitor within tau_i+tau_j using tau_i=1e-12+1e-10*abs(savedMSE_i). An ambiguity must not be presented as certified selection agreement by a future controller.

`joint_response_audit_projection.py` validates the exact nine ZIP_STORED checkpoint members, sizes, CRC reads and native FP64 NPY headers/payload lengths using the frozen reviewed header grammar. Only after all nine validate does it create three immutable bytes-backed G/U/D numeric views. Moment payloads are bounded and byte-validated, but their numerical values are deliberately not decoded or checked for finiteness: they are outside a candidate forward audit. The tests explicitly show that an unused moment NaN does not create a numeric view, while a malformed last moment header prevents every view. This is not an optimizer-state correctness audit. Original frozen source files remain unchanged.
