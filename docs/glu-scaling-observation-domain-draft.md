## Product-rule rank bound — derived here, not experimental evidence

For an owned bias-free SiLU GLU, f_o(x)=sum_i D_oi*s(G_i x)*(U_i x),

H_o(x)=sum_i D_oi*[s''(G_i x)*(U_i x)*G_i.TG_i + s'(G_i x)*(G_i.TU_i+U_i.TG_i)].

Thus all smooth Hessians lie in the span of at most2m fixed symmetric atoms in dimension p=n(n+1)/2. This is an UPPER bound; equality and recoverability do not follow. If the actually observed span is the full symmetric space, every v*v.T has zero residual to that span. A span-membership/rank-one-residual test alone then cannot distinguish the true gate directions. This says nothing by itself about full-map identifiability or alternative coefficient/tensor/higher-order algorithms. FiniteFP32 execution has no such classical smooth derivative; compare FD observations to a separately labeled ideal smooth reference only.

The fixed GLU32case n32,m64 has bound128<528. Smaller input projections need not preserve this separation: n4,m8 permits full10-dimensional span, while n8,m16 permits32of36. The second case is NOT asserted to have full span or unidentifiable gates. Dimension counting/transversality alone is not a certificate for structured GLU dictionaries; no claim about finite isolated directions is made without a separate argument.
