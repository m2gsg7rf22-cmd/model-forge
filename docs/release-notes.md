# 0.2.0 — local language engines and controlled research

Adds local built-in GPT-2/Llama SafeTensors loading, real inference, full/PEFT LoRA
updates, immutable checkpoints, HF resume, safe reconstruction/merge and explicit
rights. Heavy engines execute in an optional companion environment, keeping the
native base smaller. PySide pages expose these operations in additional tabs.

Apple Silicon MLX now performs real CPU/Metal Llama inference, 4/8-bit linear
quantization, measured benchmarking, LoRA and quantized-base LoRA updates with
integrity-checked saved-adapter reload. HF CPU/MPS and MLX GPU tiny owned fixtures
were exercised locally. MLX resume/merge and CUDA QLoRA hardware acceptance remain
unsupported or unverified respectively; training loss is not quality evaluation.

Adds bounded activation hooks and reversible named-MLP ablation; durable authorized
API ledgers with JSON Schema/context/label cases; and UMRRE controlled affine
recovery, nonidentifiability, symmetry, held-out approximation and compression.
No closed-model weights, universal architecture recovery or generative multimodal
pipeline is claimed. See [capabilities](capabilities.md) and [research evidence](research-evidence.md).

The GitHub bootstrap creates a dedicated agent environment, verifies actual MCP
calls and prepares scoped Claude/Codex integration; explicit application uses
supported host commands. Update/removal retain ownership boundaries. See
[agent installation](agent-install.md).

Focused development tests are distinct from final release acceptance. Consult
[validation](validation.md) and the published release artifacts for executed
platform/package results. The historical 0.1 record below is preserved and does
not certify 0.2 packages. Native builds are not Developer-ID signed/notarized.

# 0.1.0 — initial research release

Integrated native desktop, safe metadata inspection, evidence graph, behavioral probe lab, independent tiny causal runtime, output-head training, float32 reconstruction checks, quantized storage, persistent scheduling, real MCP server and Claude/Codex integration packaging.

This is a bounded early research product, not a universal model cloning engine. Imported-model execution, full transformer training, LoRA/QLoRA, MLX/CUDA, image/video/audio generation, activation tracing and proprietary weight recovery remain unsupported. Explicit source/format/fidelity reports accompany the supported paths.

Native archives are platform-specific. Only actual built and tested archives are eligible for a release. Builds are not Developer-ID signed/notarized. See validation.md for the test record and remaining acceptance gaps.
