# 0.1.0 — initial research release

Integrated native desktop, safe metadata inspection, evidence graph, behavioral probe lab, independent tiny causal runtime, output-head training, float32 reconstruction checks, quantized storage, persistent scheduling, real MCP server and Claude/Codex integration packaging.

This is a bounded early research product, not a universal model cloning engine. Imported-model execution, full transformer training, LoRA/QLoRA, MLX/CUDA, image/video/audio generation, activation tracing and proprietary weight recovery remain unsupported. Explicit source/format/fidelity reports accompany the supported paths.

Native archives are platform-specific. Only actual built and tested archives are eligible for a release. Builds are not Developer-ID signed/notarized. See validation.md for the test record and remaining acceptance gaps.
