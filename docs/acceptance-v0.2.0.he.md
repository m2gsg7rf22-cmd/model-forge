## מה הוכח ומה לא

**משקלים מקוריים** דורשים ראיות פרמטרים; **חישוב שקול** דורש יחס מתמטי מוגדר. **התאמה סופית** בטוקנים/logits אינה שקילות לכל קלט; **קירוב התנהגותי** אינו זיהוי משקלים או ארכיטקטורה.

UMRRE סינתטי: שגיאה אפינית `1.11e-16`; תלמיד MSE `0.02089`, רווח bootstrap `[0.01731, 0.02437]`. דחיסה משנה חישוב ואינה ללא אובדן.

מרשם כל 12 המכשולים, סיווגם, הספרות וההשערות נמצא ב־`docs/research-evidence.md`. הוא מבדיל מגבלת הנדסה, חוסר מידע, אי־ייחודיות מתמטית ובעיה פתוחה; לא מוצג פתרון לכל מכשול.

## התקנה ב־Mac Apple Silicon

1. הורד מ[ההפצה](https://github.com/m2gsg7rf22-cmd/model-forge/releases/tag/v0.2.0) את `ModelForge-0.2.0-Darwin-arm64.zip`. בדוק `shasum -a 256` מול `a6a1dd2346f5a9a4305396be45a711fcb41d926b5b419b38201be44cb5993d91`.
2. חלץ ב־Finder, גרור את `ModelForge.app` ל־Applications והפעל. חתימת ad-hoc אינה notarized; אם נחסם, אשר ב־Privacy & Security בלי לבטל הגנות מערכת, לפי [הוראות Apple](https://support.apple.com/en-il/102445).
3. למנועים כבדים: `uv` או Python 3.12+ ו־3GiB פנויים. ב־**Settings → Optional local engines** בחר `mlx` בהתקנה הראשונה ואשר תלויות. Python לבסיס כלול; משקלים לא. סביבה קיימת אינה נדרסת.
4. טען bundle מורשה; ל־Metal בחר `mlx`, מכשיר `auto`/`mps` ו־2048MiB. המודל האקראי המובנה אינו עוזר מאומן.

התקנת companion wheel אומתה בדימוי `frozen`; **לחיצות GUI ופתיחה ראשונה במחשב נקי לא אומתו**. 

מקורות: [MLX-LM](https://github.com/ml-explore/mlx-lm), [MCP SDK](https://github.com/modelcontextprotocol/python-sdk), `docs/research-evidence.md`, `docs/ecosystem.md`, `docs/agent-install.md`.

## אימון נוסף על מודל מאומן

SmolLM2-135M עבר חמישה צעדי LoRA על בסיס מכומת 4 ביט ב־MLX Metal, עם 230,400 פרמטרים ניתנים לאימון. טקסט האימון נכתב לצורך הבדיקה. האובדן ירד מ־7.09375 ל־6.125; טעינת המתאם והסקה מחדש עברו. שיא הקצאות MLX היה 341,129,864 בתים; זמן התהליך היה 4.06 שניות. אין מדידת הכללה או מבחן איכות נפרד. המשקלים והמתאם אינם מופצים. סביבת החול הראשונה חסמה גישה ל־Metal; ההרצה המאושרת מחוץ לה הצליחה, והאירוע נרשם בראיות.

## שלמות ההפצה

חבילות macOS/Linux וקובצי Python הסופיים נבנו ב־CI מקוד 952450a; Windows מקוד 177a7cd. כל 20 קובצי המנוע זהים לאחר נרמול CRLF ב־Windows. בסיס הבדיקות המלא ב־Mac/Linux הוא a9a82f2. קובצי המקור ב־wheel וב־wheel המוטמע ב־Mac הושוו למקור המאומת. הורדת artifacts בוצעה בחלקים לאחר timeout, עם התאמת digest של GitHub ובדיקת manifest של כל חבילה. דוגמת המודל כוללת רק משקלים בבעלות הפרויקט; נתיבי מחשב הוחלפו בתוויות מקומיות במטא־דאטה, ובתי הטנזורים נשארו זהים. SHA256SUMS.txt כולל את כל נכסי ההפצה פרט לעצמו. גרסה 0.1.0 נשמרה ללא שינוי.

## תיקון תאימות Windows

בדיקת MCP המאובחנת הראתה שיצירה, טעינה והסקה הסתיימו בכ־5 שניות כל אחת. קריאת UMRRE נתקעה בטעינת NumPy multiarray הראשונה בתוך לולאת asyncio של Windows; ה־stack trace נשמר בריצת 39602001915. הודעת BrokenResourceError בזמן סגירת SDK הסתירה את פסק הזמן האמיתי בחלק מהריצות הקודמות. הקוד כעת טוען את NumPy לפני הפעלת לולאת השרת, ללא שינוי אלגוריתמי מנועים. בדיקות Windows המלאות ב־39603372621 ובדיקות MCP והאריזה המעודכנות ב־Mac/Linux הן שערי השחרור הסופיים.
