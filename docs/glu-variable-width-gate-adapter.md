# Variable-width public gate adapter — component validation

New source: `examples/isolated_glu/variable_gate_view.py`; tests: `tests/test_variable_gate_view.py`. This component performs no optimization, teacher forward, query, RNG, model generation or private-data access. No actual paired-v1 arrays were loaded during this component work. Existing31 signed sources are unchanged.

`load_bundle(public_root, estimator_root, commitments)` requires the registered6base/12condition/54public-archive domain. Its four explicit metadata pins bind public cases/manifest and estimator seal/report. The adapter checks every physical public archive schema/hash, all24 estimator archive schemas/hashes, all12 ordered selection records and every rule's native rank/projector. Stable p17 supplies the first r Richardson basis rows only; full q-row source bases never pass as the selected rank. All public source bindings and estimator metadata/archives/inventories are rechecked before returning any optimizer job.

The optimizer receives frozen `GateJob(job_id,basis)` objects only: job00..05, bytes-backed immutable basis, derived dimension/rank. Original IDs/channel metadata remain in separate `GateBundle.provenance`. Caller must pass only `.jobs` to the future optimizer. Generic jobs require symmetric coordinates n2..32, proper even rank<=192 and orthonormal native FP64 rows. Even rank/r/2 remains a family hypothesis, never a width or coverage certificate.

The private `_load_fixture_bundle` seam applies the same seal checks to tiny synthetic public inputs; the registered entry rejects that fixture domain. Tests use n2/r2 source archives and literal identity-basis jobs at n3/r2,n8/r32,n32/r192. They check mutated unused16 archives, mismatched ranks, native bool/integer confusion, case order, metadata/provenance, missing source commitments, immutable copies, nonfinite/malformed geometry, symlink/size gates and reading only explicit public/estimator roots. A late extra estimator file first reproduced a missing final inventory check (RED); rechecking both estimator directories fixed it (GREEN).

Local validation:32 fixture tests passed in0.47s; strict mypy1source and Ruff2files passed. Initial missing-module RED was observed before implementation. One test's expected file count was corrected from17 to18 (11public+7estimator); this was test arithmetic, not a numerical research failure. No successful scientific experiment, native package or broad integration suite was rerun.

Limits: checks bind committed artifacts and schema; this adapter does not independently rerun rank selection or establish that a basis identifies gates. Original rank outputs already have their own saved-output audit. Canonical job order is known and is not statistical/cryptographic blinding. Public/truth separation is a source/dataflow contract, not OS isolation or protection against an attacker restoring files between checks. Final hashes are mutation detection, not a filesystem snapshot. Full source, inventory, controller, preregistration, resource approval and clean freeze remain mandatory before registered fitting. Separate independent component review is stored under `experiments/evidence/variable-width-gate-adapter-v1/`; it is not full experiment approval. Main universal/full-function/weights/bias/HVP/weaker-access/backbone goals remain open; private gate CLOSED.
