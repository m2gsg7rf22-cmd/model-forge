# UMRRE — Universal Model Reconstruction Research Engine

UMRRE is a runnable, bounded reconstruction research suite. Its name describes the research objective; it does **not** mean universal reconstruction has been achieved. The current engine uses small project-owned synthetic targets, no remote requests, and no paid APIs.

```python
from modelforge.umrre import run_research, recover_affine
report = run_research("new-experiment-directory", seed=7)
```

`run_research(destination: str | Path | None = None, *, seed: int = 7) -> dict` executes the complete suite, measures cost, and atomically writes `umrre-results.json` if a destination is supplied. The destination must be new; existing directories and symlink ancestors are rejected. A Service wrapper should generate a fresh directory per run. Seed is an integer from 0 through 2³²−1. Workload sizes are fixed, so neither user input nor a remote endpoint can increase the allocation or query count. To enforce a process memory/time ceiling, invoke through ModelForge's bounded worker; the in-process library only samples memory.

`recover_affine(oracle, dimensions) -> (weights, bias, query_count)` is independently usable. It receives only a callable oracle and the known input dimension, bounded to 64. It queries zero and basis vectors, validates finite output shape, and returns the recovered matrix and bias. It never receives the target parameters. Ground truth is inspected separately for evaluation.

The suite runs six groups:

| Experiment | Computation and evidence | Scope |
|---|---|---|
| Affine recovery | Nine vector queries recover 27 parameters of a known 8→3 affine map; 256 independent test inputs | Noiseless real-valued outputs and known family; float64 tolerance |
| Rank-deficient observations | Construct a nullspace perturbation after four queries in eight input dimensions; show indistinguishable observed outputs and different unseen witness output | A constructive counterexample, not a claim that every extraction is impossible |
| Neural symmetry | Permute and positively rescale hidden ReLU units, compensating outgoing weights; verify different weights and matching outputs | Algebra establishes all-input functional identity; 256 numerical checks illustrate it |
| Functional approximation and architecture search | Train three random-feature tanh students of width 8, 16, 32 with ridge regression using 256 oracle training examples; choose by 128 validation examples; evaluate on 256 untouched examples | New student weights approximate a fixed teacher distribution; neither original architecture nor weights identified |
| Compression | Actual SVD rank-4 approximation, structured column pruning, symmetric INT8 storage and dequantized computation; quantized keys/values in actual scaled dot-product attention | Records representation bytes and output error; no inference speedup claim; no production KV-cache integration |
| Multimodal adapters | Flatten owned image/audio/video tensors and reconstruct affine projections | Real tensor operations, not image/audio/video generation or recovery of diffusion weights |

The approximation confidence interval is a 200-resample percentile bootstrap over independent held-out examples. It describes this finite-sample error estimate under the stated Gaussian input distribution; it is not confidence in a recovered proprietary architecture. Compression sizes count numeric payload and explicit scales/indices, excluding file-format headers, Python objects, and temporary dequantized matrices. Every compression method changes the computation.

All data are independently generated by seeded NumPy streams. The numerical hash excludes timing and platform fields. Repeated runs within the same numerical environment should match it; BLAS implementations and NumPy versions may change last-bit results. Reproduce with the recorded Python, NumPy version and seed. Timing and sampled process RSS include interpreter overhead and are environment dependent; 10ms sampling can miss transient peaks.

No MoE optimization, unrestricted architecture discovery, semantic multimodal reconstruction, or closed GPT/Claude weights are implemented. Their absence is reported explicitly. See [the evidence and obstacle register](research-evidence.md).

## Verified reference run

On macOS 26.3 Apple Silicon, Python 3.12.15 and NumPy 2.5.4, seed 7 completed in 0.293 seconds with sampled peak process RSS 38,830,080 bytes. There were 544 construction/training oracle queries and 816 separate evaluation queries. Compression has 256 additional local evaluation inputs and eight attention queries; those use accessible owned weights and are not charged to the hidden-oracle count.

- Maximum affine parameter error: 1.11×10⁻¹⁶; held-out MSE: 5.25×10⁻³².
- Nullspace model pair: observed maximum difference 1.33×10⁻¹⁵, unseen witness difference 3.0.
- Symmetric neural models: weight distance 13.218; maximum test output difference 7.11×10⁻¹⁵.
- Approximate student: selected width 32; held-out MSE 0.02089 versus zero predictor 0.32609; bootstrap interval [0.01731, 0.02437].
- INT8 weight representation: 776 versus 6,144 float64 bytes; output MSE 0.001911.
- INT8 KV representation: 2,064 versus 16,384 bytes; attention-output MSE 4.13×10⁻⁶.

These are one controlled run, not frontier model benchmarks. `tests/test_umrre.py` checks independent hidden affine targets, nonidentifiability witnesses, nontrivial approximation, compression errors, reproducibility, bounds, and safe report creation. Ten targeted tests passed in the initial verification.
