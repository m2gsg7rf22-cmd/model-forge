# אודיט עצמאי — paired row acquisition v1

האודיט עבר. שני הכללים עומדים ב־endpoint הסופי הרשום בתנאי 17: כל אחד עבר בכל ששת מקרי teacher/channel. אין בכך אישור לשיטה כללית או למחקר נוסף.

מקור הניסוי: `07235acd0ecaa576d57b37eefb2b4e6fc3aa0c6a`. אומתו 31 קבצים חתומים ו־24 runtime pins מול commit המקור והמצב הנוכחי, ancestry, הרישום, marker חד־פעמי, קבלות outer ושלבים, מקור 54 הארכיונים הציבוריים, 24 ארכיוני האומד, וכל 522 הארכיונים המדעיים ו־10 ארכיוני transport. נתוני המקור נשארו ללא שינוי.

כל 12 הבחירות חושבו מתצפיות בלבד, ונבדקו spectra, right bases, פערים, מועמדויות 512/527, יציבות, projectors ו־seal לפני פתיחת truth. קידומת 16 זהה ביטית ל־512 השורות הראשונות של 17 בכל שלוש התצוגות. לאחר מכן נבדקו commitments, מיפוי זהויות באמצעות hash בלבד, ששת ההקשרים, עיגול FP32, product-rule analyticH, כל פינות הסטנסיל ו־204 תגובות שמורות. נספרו 430,848 וקטורים, ללא query נוסף.

FD fine/coarse ו־Richardson שוחזרו מהתגובות השמורות בדיוק ביטי. analyticH עצמאי: הפרש מוחלט מרבי 2.9976021664879227e-15, יחסי Frobenius עד 1.0131098765308984e-15. הפרש stability מרבי 1.1973148167365721e-13. כל החלטות הדרגה, הספים וההכרעות תואמות. נבדקו ששת methods, כל רכיבי SVD ו־padding, מדדים גאומטריים, residuals, בקרות רוחב, clipping/collisions, אפס/full/sensitivity ו־null metadata לפי הסכמה.

ספירות תיאוריות לכל ששת methods: `{'16': {'strict': 0, 'gap': 3, 'stable': 4, 'known_width': 6, 'wrong_width_half': 0, 'wrong_width_double': 0}, '17': {'strict': 0, 'gap': 6, 'stable': 6, 'known_width': 6, 'wrong_width_half': 0, 'wrong_width_double': 0}}`. בכל זוג לא השתנתה דרגת reference או הרגישות לשלושת הספים; לא אבד אף pass של 16 ב־17. gap השתפר מ־3/6 ל־6/6 (שלושה gains, אפס losses); stable מ־4/6 ל־6/6 (שני gains, אפס losses). אין לבחור ביניהם כלל מנצח.

בשלושת ערוצי FP32 של תנאי 16 נבחר gap=512, לעומת reference=192/96/32; ה־padded structural boundary אושר עצמאית. ב־17 הוא הוחלף בדרגת reference המתאימה. במורה width96 שני ערוצי stable עברו מ־null ל־192. זהו שיפור מזווג במדגם הרשום; אין הוכחה שכל הוספת probe תפתור רעש או כשל זיהוי.

האודיט הופעל בניסיון מספרי אחד לאחר preflight TREE שעבר (17,137,664 בתים, 3 דגימות). האודיט: process_and_children, ‏230,096,896 בתים מדוגמים/54 דגימות, מגבלה 512MiB/180s, זמן launcher כולל preflight ‏3.395843709 שניות.

הניסוי המקורי: outer TREE ‏499,023,872 בתים/132 דגימות; זמן פנימי לפני כתיבת הדוח הסופי 7.721474000 שניות. retained bytes לאחר outer report: ‏523,058,572, בתוך התכנון 534,980,568 ומתחת 1GiB. אין לפרש RSS מדוגם כהוכחת שיא רציף.

מגבלות:
- לא בוצעו RNG, יצירת מורה, model forward, שאילתות או fitting באודיט. שקילות ערכי התגובות המקוריים למורה לא נבדקה באמצעות replay; נבדקו hash/schema וערכי הנגזרות מהתגובות השמורות בלבד.
- מקור הגרלות גורמים/נקודות/בקרות לא שוחזר. הקצאת זהויות נבדקה באמצעות hash של seed שמור לאחר seal, ללא פרסום seed/nonce או יצירת דגימות.
- analyticH הוא חישוב FP64 מקורב מהגורמים השמורים. reference לערוץ FP32 הוא הפונקציה החלקה ב־FP64 אחרי עיגול הגורמים פעם אחת, לא נגזרת של התוכנית המעוגלת.
- RSS הוא שיא דגימות process_and_children ולא חסם שיא רציף או הקצאת OS. זמן הבקר המקורי נמדד לפני כתיבת הדוח הסופי; זמן launcher האודיט כולל preflight וכתיבת קבלות.
- שלושה מורים בלבד עם ערוצים וקידומות תלויים; הצלחה כאן היא endpoint סופי ציבורי של תת־מרחב בתנאים הרשומים. אין להסיק על כל רוחב, near-parallel/duplicate, bias, gates מזוהים, פונקציה מלאה, משקולות או שחזור אוניברסלי.
- אין שיטת דירוג חדשה או בחירת כלל מנצח. הבדיקה אינה מתקנת את כישלון 24 המקרים הקודם; certificate=false והשער הפרטי סגור.
- סדר public→seal→truth אומת במקור ובבודק האודיט, ללא טענה להפרדה מול תוקף או לעיוורון סטטיסטי של החוקר.
