Twelve fresh owned bias-free isolated SwiGLU blocks have input/output dimensions4/8/16/32, three registered widths per dimension:2/4/8,4/12/20,8/24/48,16/48/96. Both FP64 and FP32-compute channels use the same original factors/probes. Factors are independent normal draws scaled.2; probes16 normal draws scaled4; controls64 independent normal directions. The n16/width24 case copies the last g/u row from the first without changing d. The n16/width48 case adds separate1e-6*(.2*normal) perturbations to those rows before rounding. This is24 paired channel cases, not a held-out population guarantee.

A256-bit entropy seed and nonce are drawn only after the source, resource and global-marker gates. Widths within each dimension are hash-sorted with that seed into anonymous c00..11 slots. Canonical seed/nonce/mapping JSON is SHA256 committed before any factor RNG. Teacher seeds are domain-separated SHA256 values with bit255 set; consumed small seeds cannot collide. These commitments protect chronology in the trusted workflow; source separation is not an OS sandbox or cryptographic blinding against an adversarial host.

Each probe uses all four signed corners for both steps.3/.6, including repeated diagonal rows. Every input archive and attempted-slot intent precede its callback; the detached returned archive precedes derivative arithmetic. Returned counts mean callback slots, not finite-value certificates; persisted counts require strict schema/finite transport. Failure preserves reservations/partial counts and stops without retry. Planned545280 vector slots and768 callback batches are engineering budgets, not observed results.

The FP32 analytic reference rounds factors once to float32 and evaluates smooth derivatives in float64; it is not a derivative of rounded execution. Reference matrices have16*n rows and p=n(n+1)/2 columns, q=min(16*n,p). All spectra pad structural p-q zeros. Primary reference relative cutoff1e-10, side cutoffs1e-11/1e-9. Any side-rank difference is sensitivity FAIL, including primary fullp. Zero reference is FAIL. No exclusions or retuning after reveal.

Observation-only selection is byte-frozen `rank_selection.py`: strict1e-10, spectral gap10, three-view prefix stability.01 and resolution floor64*epsilon*max(rows,p). All24 choices/bases/projectors/diagnostics and all144 public input hashes are sealed before any truth read. Both gap and stable rules are reported independently over all24 cases. They are not selected against truth. Estimator receives only public FD metadata, input hashes, its output path and estimator caps; it does not import the private factory or width inventory.

Privileged evaluation validates every ordered case/public metadata/rank/archive descriptor/header/basis/projector before opening registration or truth. Then it validates the source-bound seed commitment and the pre-estimation truth/public commitments. Reference proper-subspace endpoint requires matching rank, lost/extra geometric subspace errors<=.01, true-gate max residual<=.01 and random-control min strictly greater than true-gate max. ## Auxiliary metrics and exact inventory extension

The aggregates are named `reference_relative_residual` and `observed_relative_residual`: ||A(I-P)||F/||A||F, not squared energy fractions. The reference per-component amplitude is c_j=(sigma_j/||sigma||2)*||v_j(I-P)||2 for every available right singular vector, with structural zeros padded to p. Its square is the normalized per-component residual energy fraction; the L2 norm of c equals the reference aggregate. Individual components in degenerate singular spaces depend on the chosen SVD basis. Their squared sum is basis-invariant; IDs are not aligned across channels. Zero denominator produces null/-1 sentinel and cannot rescue a failed endpoint. Scaling guards preserve representable small residuals and reject normalization/weighted underflow to zero.

## Trusted execution and resource receipts

The preregistration binds all17 runtime source dependencies, policy, exact expanded inventory and installed Python/NumPy versions. Independent full-source review must also sign the tests, this protocol, parent design, implementation plan and preregistration. Exact current hashes, clean committed discovery-lab and fixed HEAD are checked before data and between stages. Component approvals do not satisfy this gate.

Supported launch is the default `fresh_rank_controller.py` JSON CLI with repo/output/config/review paths. It invokes a second controller process through frozen `modelforge.execution.run_json`, with an outer shared180-second timeout,512MiB polled process-and-children RSS, BLAS1 and combined stdout/stderr<=2048 bytes. This outer monitor includes controller imports, parent-side NumPy validation, every worker and Git child. The small host launcher is excluded. RSS is sampled, not reserved by the OS, and sampling can miss short peaks. Worker-specific receipts and shared-deadline checks supplement, rather than replace, the outer receipt. Calling `run_protocol`/controlled_run directly does not establish the complete resource contract.

Within the monitored controller, a synthetic monitor-scope preflight and all seven maximum literal-zero transport roundtrips precede actual free-disk validation and an exclusive, fsynced global marker. The marker at experiments/fresh-variable-width-rank-v1-attempt.json binds source/config/output before any entropy. Existing/partial marker or existing output means no retry. Data root is a direct child of the durable experiments directory outside Git. Collection, estimation and evaluation run sequentially with necessary inputs only. A failure status is preserved with its resource receipt before rejection. A killed/unreceived worker leaves counters unknown; saved query-progress counts remain lower-bound evidence, never fabricated zeros.

Before inner completion, exact four scientific stores, schemas, names, manifests and per-store caps are validated. Exact metadata/layout rejects extra root NPZs, reports or directories. Temporary engine request/output/log files are bounded by the engine and removed;8MiB reserve covers metadata, transient requests/logs, and final reports. Total retained files plus that reserve must be<1GiB. The outer monitor writes outer-monitor.json only after monitored termination, binding the inner controller report digest; no result is resource-valid without a successful process-and-children outer receipt. Failed outer monitoring cannot promote inner numerical success. Final saved-output independent audit remains a distinct required step.
