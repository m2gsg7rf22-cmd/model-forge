Physical coefficients are compared separately against the transformed selected normalized parameters. Every saved prediction shard (8192rows in the actual profile) is independently checked in three ways: normalized selected forward times sy versus saved predictions, stored physical forward versus saved predictions, and normalized versus physical forward. Each forward chunk is<=4096rows; both maximum and Frobenius tolerances are evaluated over the complete stored shard. These functional checks are necessary because coefficient absolute tolerance alone can conceal amplification when input scale is large. The new regression fails before the fix and correctly reports disagreement afterward. No original model observations were used to discover or repair this bug.

The result separates prediction rows visited from rows actually compared; arithmetic failure cannot be counted as verified prediction rows.
