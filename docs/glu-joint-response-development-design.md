## Fixed calibration split and model coordinates

For each case, retain both steps and all rows. Probe indices3,7,11,15 form a calibration guard; the other13centers form training. Whole centers stay together across both steps and paired channels. Training has54912rows; guard16896; each case has71808rows. The width hypothesis uses the original all17-probe rank observations, including the guard centers. This is not cross-fitting or an unbiased generalization estimate; the guard is consumed model-selection calibration. These local stencil rows contain duplicates/dependencies and are not71808independent broad-domain observations. Uniform row weighting deliberately preserves the acquired multiset; no adaptive deduplication or filtering.

Compute only from training: `sx=sqrt(mean(X_train**2))`, `sy=sqrt(mean(Y_train**2))`; require finite sx/sy>1e-12 or abstain. Learn on Z=X/sx and T=Y/sy. Physical parameters are G=G_normalized/sx, U=U_normalized/sx, D=sy*D_normalized. This rescales conditioning, not physical precision. The guard uses the same training-derived scales. Validate each case normalization before creating that case streams; global source/input/rank/resource gates do not require caching all six datasets. Predictions are FP64 candidate arithmetic; FP32-computed observations remain FP32-computed even when stored/scaled in FP64.

For width hypothesis m, initialize normalized G/U as independent standard normals divided by sqrt(n), D as independent normals divided by sqrt(m). No prior gate candidate is injected. Use shared optimizer random numbers within each precision pair to control initialization/sampling: group00forjobs00/01, group01for02/03, group02for04/05. Derive independent initial/batch stream integers by big-endian SHA256 of `modelforge-joint-response-development-v1/groupNN/initial` and `/batches`, using injected PCG64 generators created only after every gate. Persist before/after states, initial arrays and all batch indices. Equal paired widths and input ordering give identical normalized initial arrays and batch schedules; observed target/scales may differ. There are three owned teachers with dependent channels, not six independent trials or proof of a general precision effect.

## Fixed joint optimizer and selection

Use one run per case,4000Adam updates, batch256 with replacement from training rows, moments.9/.999, epsilon1e-8. Precompute/persist the complete4000x256integer schedule before the first update; use its rows in order. Learning rate follows a fixed cosine schedule from.01atupdate0to.0001atupdate3999. No weight decay, clipping, norm-balancing, extra restarts, early success, candidate-count acceptance or threshold relaxation. These are prospective development settings, not known effective values. Nonfinite/overflow arithmetic is a recorded numerical case failure; do not return a partially invalid model as a completed fit. IO/resource/source failures terminate the entire attempt with partial receipts.

Objective is `.5*mean((prediction_normalized-target_normalized)**2)` over each sampled batch. Derive analytic gradients for G/U/D, validate against independent finite differences and a separate literal forward formula before use. Stable SiLU/sigmoid evaluation must avoid artificial exp overflow. New kernel functions are pure numeric inputs/outputs, with no filesystem, target, private metadata or teacher imports.

Atstep0, every256updates, andstep4000, compute full training/guard calibration losses and guard Frobenius relative error, in bounded chunks. There are17checkpoints. Select the earliest minimum FINITE guard normalized MSE; a guard is model-selection calibration, not an unseen test. Do not inspect true parameters, original rank labels, old consumed evaluation files or fresh data. Report initial/final/selected errors, selected step, all17checkpoint metrics and actual completed steps for EVERY case. No fixed quality-success label is assigned from these calibration values; the4000update cap does not prove convergence. Step0may win and is reported honestly. A numerical failure remains failure rather than a selected-prefix success.
