# ביקורת מקור עצמאית — סבב ליטוש צימודים

מאושר פרוטוקול ניסוי ציבורי יחיד, בכפוף ל־commit נקי של חתימות הסקירה לפני ההרצה. אין ממצא חוסם. האישור אינו אישור תוצאה, ירידה בפועל או איכות מועמד. נבדקו חמשת הקבצים החדשים, שש התלויות הקפואות והבקר; פרימיטיב rank-one תואם בדיוק למקור שאושר בסקירה הסינתטית הקודמת.

ארבעת הקלטים מחויבים בחתימות; manifest מחבר ל־Hessian ולדוח המועמד הקודם. המקור הקפוא מאשר את 64 נקודות הבסיס בזרע 20261024 ובקנה מידה 4. נבדקו דירוג 64 הצעות מול אותו residual התחלתי, שבירת שוויון באינדקס, עד שמונה הצעות מעל margin קבוע, סבב יחיד ללא מיון חוזר, חישוב partial מעודכן ושמירה רק בירידת היעד המלא. הספירה חסומה ב־72 פתרונות אלגבריים. מקור ההתאמה אינו מייבא מורה או קורא קובצי אימות שנצרכו; שערים מועתקים ללא שינוי. אין ridge או שינוי כיוונים; אי־יציבות whitening דוחה במקום דילוג שקט. קבלת פלט דורשת צימודים סופיים, סופיים מספרית, לא־אפסיים ומדרגה אחת.

שלושה פרובים סינתטיים עצמאיים עם חמש יחידות בדקו דירוג, סדר עדכונים, החלטות שמירה ופתרונות מקומיים בקואורדינטות Cholesky. חישוב מלא מחדש מהמועמד הסופי תאם ל־residual האינקרמנטלי עד יחס 3.85e-15. הבדיקה הראשונית השתמשה בשוויון ביטי בין חיבור כל האופרטורים לחיסור רציף; הבדל סדר פעולות תקין חייב השוואה מספרית במקום. אין בכך כשל מוצר. לא נקראו Hessian אמיתי, כיול מורה או אימות.

AST המעריך זהה למעריך הקודם מלבד מזהה שיטה וזרע חדש 941029. דחיית מועמד שלא נבנה קודמת לגישת המורה, והחתימות נבדקות לפני הגישה. הבקר מוודא את חתימתו, חתימות המקור ומצב Git נקי, יוצר תיקייה ייחודית, מגביל בנייה ואימות בתקציב משותף 180 שניות, ומדלג על האימות בעת דחייה. מגבלת 512MiB היא בדיקת RSS מדגמית של כל עץ עובד עוקב, ולא הוכחת שיא רציף.

ביקורת התוצאה חייבת לחשב residual מלא מחדש מהמועמד הסופי, לבדוק שערים זהים ודירוג/החלטות מול הלוג. ירידת כיול אינה הכללה; השערים נשארים קבועים ולכן שגיאת כיוון אינה מתוקנת. תוצאת הניסוי עדיין לא ידועה. הכשלים הקודמים נשמרים והשער הפרטי סגור.

תיקון ראיות לפני ההרצה: נבחנה הגרסה הסופית השומרת את כל 64 הצעות הצימוד הראשוניות ואת כל ההצעות הסדרתיות בקובץ חתום coupling-proposals.npz. לכן ניתן יהיה לחשב מחדש את כל עלויות הדירוג והחלטות השמירה ללא פתרון מקומי נוסף. פרוב סינתטי בדק את עלויות ההצעות שנשמרו ואת התאמת הצורות, כולל sequential ריק בצורה (0, outputs, d). חסם הראיות הזמני נסגר; approved=true בחתימות הסופיות בלבד.
