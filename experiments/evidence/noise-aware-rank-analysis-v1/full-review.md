# ביקורת עצמאית: ניתוח rank של תצפיות ציבוריות שמורות

אושר המקור לפרוטוקול אחד עתידי, ללא שאילתות או fitting חדשים, ורק לאחר commit נקי ואימות כל החתימות ושערי המשאבים בבקר. זהו אישור מקור; הניתוח בפועל לא בוצע בביקורת זו. שער המודל הפרטי נשאר סגור.

הליבה משתמשת רק בשלוש מטריצות התצפית. נבדקו עצמאית גבול יחס10, שוויון ויציבות projector, שינויי scale, מקרים מלאים/חסרי rank ודוגמת common bias. היחס נבחן לפני log; הרצפה היא מוסכמה נומרית ביחס לערך הסינגולרי המוביל, ולא חסם רעש. כל certificate=false.

בצינור הסינתטי נשמרו ונאטמו בחירות כל המקרים לפני פתיחת context/reference. שינוי תצפית או choice archive לאחר האטימה נדחה לפני truth. נבדקה נוסחה ידנית של lost-signal=√0.5 ו-extra=0. המדד גאומטרי ואינו אובדן אנרגיית Hessian. נשמרים requested/effective ranks ו-clipping/collision של בקרות רוחב. השינוי האחרון לכתיבת JSON נבדק בנפרד: short write מותיר רק קובץ זמני ואינו יוצר seal סופי.

בפרוב עצמאי של הבקר נבנו48 קובצי פלט קטנים ו־528 קלטים מילוליים. אומתו נתיב תקין, דוח שסותר את האטימה, סדר מקרים שגוי, שינוי קלט, marker שגוי ושינוי מסמך חתום. עם engine סינתטי נבדקו הצלחה, כשל transport, scope שאינו TREE ושינוי commit לאחר worker. קבלות הכשל נשמרות וסטטוס failed גובר על תוצאות חלקיות. פרובים אלה אינם מוכיחים זמינות TREE או תקרת זיכרון אמיתית; לכך נדרשות קבלות הריצה העתידית.

אומתו10 תלותי runtime מול הרישום וכל20 קובצי המקור החתומים של הניסוי הקודם נותרו ללא שינוי. החתימה המלאה כוללת runtime, ארבע בדיקות, פרוטוקול, תוכנית ורישום. בדיקות ההורה49/mypy4/Ruff8 מדווחות בנפרד; לא הורצו שוב ללא צורך. אין ממצא חוסם שנותר.

מגבלות: לא נקראו נתוני הניסוי המקוריים, תוויות941xxx או נכסים פרטיים; לא הופעלו RNG רשום, oracle, forward או fitter. הפרדה לפי מקור אינה sandbox או עיוורון סטטיסטי. פערים יציבים אינם תעודת rank, והניתוח הציבורי אינו הוכחת שחזור או שקילות. אחרי הריצה היחידה עדיין נדרשת ביקורת עצמאית של התוצאות השמורות לפני מסקנות מדעיות.

ראיות וחתימות מדויקות מופיעות ב-source-review.json; הפרובים נשארים קטנים והנתונים הגולמיים אינם מועתקים ל-Git.
